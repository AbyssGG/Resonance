# Support

## Getting Help

For general usage questions, build issues, and integration questions, please use GitHub Issues.

When asking for help, include:

- operating system
- Nim version
- OpenVINO Runtime version
- target device, such as `CPU`, `GPU`, or `NPU`
- relevant model information
- reproduction steps
- error messages or logs

## Maintainer Contact

For private matters such as security reports, contact the project maintainer directly.

If a dedicated private contact address is added later, this document should be updated to include it.
