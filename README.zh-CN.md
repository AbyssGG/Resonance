## 项目定位

`Resonance` 是从 `NimVoice` 中抽离出的 OpenVINO C API 封装层，目标是沉淀为一个可独立开源、可复用的 Nim Wrapper / Binding 库。

```text
Nim
  ↓
OpenVINO C API
  ↓
Intel NPU
```
