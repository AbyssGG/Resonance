# Language Guide

This repository uses **English as the default documentation language**.

## Policy

- `*.md` files in the project root are written in English by default
- Chinese content should live in separate, explicitly labeled documents
- English documentation is the canonical version for public and open-source presentation
- Chinese documentation is optional and should be treated as an additional accessibility layer

## Switching Between English and Chinese

Use the following convention when both language versions exist:

- English: `README.md`
- Chinese: `README.zh-CN.md`

Examples:

- `ARCHITECTURE.md` / `ARCHITECTURE.zh-CN.md`
- `ROADMAP.md` / `ROADMAP.zh-CN.md`
- `MIGRATION_FROM_NIMVOICE.md` / `MIGRATION_FROM_NIMVOICE.zh-CN.md`

## Current Repository Status

- English documents are the primary public-facing documents
- Chinese documents are added only when explicitly needed
- If a Chinese version does not exist yet, the English version is the source of truth
